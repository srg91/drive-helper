Privacy policy

Drive helper (personal) is used only by its owner, with Google accounts that belong to the owner. It reads and changes Google Drive, Docs and Sheets files only to carry out the owner's own requests.

To answer a request, the relevant file content is processed by an AI model provider (Anthropic) on the owner's behalf and kept only in the owner's private storage. It is not sold, not shared with anyone else and not used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed at any time on myaccount.google.com (Security, third-party connections).
